# FinanceApp Project

Welcome to FinanceApp. This is a personal finance management system.

## Global Instructions
- **Language:** Always use English for code, comments, and documentation.
- **Commit Style:** Use descriptive commit messages in English.
- **Testing:** Ensure both frontend and backend are tested before significant changes.

## Directory Index
- `./frontend/`: Frontend application details.
- `./backend/`: Backend API details.
- `./scripts/`: Automation and development scripts.

## Developer Scripts
The `./scripts/` directory contains convenient scripts to manage the application:
- [test_all.sh](file:///workspaces/finance-app/scripts/test_all.sh) - Runs all backend (pytest) and frontend (jest) tests at once.
- [format_all.sh](file:///workspaces/finance-app/scripts/format_all.sh) - Automatically formats the entire codebase (python with black, typescript with prettier).
- [check_format.sh](file:///workspaces/finance-app/scripts/check_format.sh) - Checks codebase formatting correctness without writing changes (dry-run).
- [run_local.sh](file:///workspaces/finance-app/scripts/run_local.sh) - Runs both frontend and backend development servers locally.
